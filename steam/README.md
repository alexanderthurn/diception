# Steam files

Three different kinds of file live here and they are easy to confuse, because
nothing in the names says which is which.

## Shipped with the game

| File | |
| --- | --- |
| `game_actions_X.vdf` | Steam Input action manifest — the action names shown on Steam Deck and in the controller configurator. Localized (english / german / spanish / schinese). |

It is **copied** into `dist-tauri/{win,mac,linux}/` by the `tauri:build:*` scripts
in `package.json` and by `scripts/electron-postbuild.js`, and the depots pick it
up from there. Electron includes it via `build.files` in `package.json`.

## Read by the build, never shipped

| File | |
| --- | --- |
| `app_build.vdf`, `app_build_{win,mac,linux}.vdf` | steamcmd build scripts. App ID `4429000`. |
| `depot_build_{win,mac,linux}.vdf` | Depot definitions: win `4429001`, mac `4429002`, linux `4429003`. |

Every depot's `ContentRoot` points at `../dist-tauri/<platform>`, **not** at this
folder — so nothing here is swept into a depot except the file named above.

`steam/output/` is where steamcmd writes build logs and its chunk cache. It is
gitignored.

## Uploaded by hand in Steamworks, never shipped

| File | Where it goes |
| --- | --- |
| `4429000_loc_all.vdf` | Stats & Achievements → Achievements → localization import |
| `storepage_1106365_all.json` | Store Presence → Localization |

Both are exported from Steamworks, filled in here, and uploaded back. Do not
hand-edit them — regenerate instead, so the text cannot drift from the game:

```
python scripts/steam-achievement-loc.py    # 4429000_loc_all.vdf
python scripts/steam-storepage-loc.py      # storepage_1106365_all.json
```

Both read `src/locales/*.json` and are idempotent. They rewrite only the token
values, leaving the surrounding structure byte-identical, so re-downloading
after an upload diffs cleanly.

A language only appears in these files once it is enabled for the app in
Steamworks and the file is re-exported — the generators fill blocks that exist,
they do not create them.

## Store page section titles

The store page's section headers are images, one set per language, generated by
`scripts/steam_assets.html` → **Download Titles in all languages**. Upload them
in Steamworks as *localized versions* of the same asset, which is why the store
page BBCode references one name (`grid_control_title`) in every language.
